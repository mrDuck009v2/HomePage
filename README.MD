# Кастомная домашняя страница для Firefox

Это моя персональная домашняя страница для браузера Firefox. Это не просто статичная картинка, а полноценное приложение с виджетами, погодой, часами и интеграцией с медиаплеером Windows.

## Что умеет

*   **Поисковая строка** — быстрый поиск в Google, YouTube, Википедии и GitHub. Поддерживает математические вычисления прямо в строке (например, 2+2*3).
*   **Кастомизация внешнего вида:**
    *   **Фон:** можно выбрать небо, градиент или свою картинку.
    *   **Эффект стекла:** настройка прозрачности и размытия кнопок (Liquid glass / матовое).
    *   **Шрифты:** отдельная настройка шрифта для часов и текста. Можно загрузить свой шрифт.
*   **Виджеты:**
    *   **Погода:** отображается для выбранного города.
    *   **Задачи:** простой список дел.
    *   **Таймер:** обратный отсчёт.
*   **Интеграция с "Now Playing":**
    *   Показывает название текущего трека, исполнителя и альбом.
    *   Отображает обложку альбома.
    *   Показывает позицию воспроизведения и общую длительность.

## Установка и настройка

### 1. Размещение домашней страницы

Поскольку страница должна работать локально и сохранять ваши закладки, настройки и данные, её не нужно выкладывать в интернет. Все файлы просто лежат у вас на компьютере.

1.  **Скачай репозиторий**. Ты можешь либо клонировать его, либо просто скачать как ZIP-архив и распаковать в удобную папку (например, C:\HomePage).
    ```
    git clone https://github.com/mrDuck009v2/HomePage.git
    ```
2.  **Найди путь к файлу**. Открой папку с проектом, найди файл home.html и запомни полный путь к нему. Например: C:\HomePage\home.html.
3.  **Настрой Firefox:**
    *   Открой Настройки → Домашняя страница.
    *   Выбери режим "Домашняя страница" или "Свои адреса".
    *   Вставь ссылку на локальный файл. Ссылка должна начинаться с file:///.
        Например: file:///C:/HomePage/home.html
        *(Обрати внимание на прямые слеши / вместо обратных \ — это важно для Firefox).*

Теперь при открытии новой вкладки у тебя будет загружаться твоя локальная страница. Все настройки и закладки, которые ты добавишь через интерфейс страницы, будут сохраняться прямо в браузере на твоём компьютере и не будут зависеть от интернета.

### 2. Настройка "Now Playing" (опционально)

Чтобы на странице отображалась информация о текущем треке, нужно запустить локальный сервер.

1.  **Установи зависимости** (один раз в терминале):
    ```
    pip install winrt-runtime winrt-Windows.Foundation winrt-Windows.Foundation.Collections winrt-Windows.Media.Control winrt-Windows.Storage.Streams
    ```
2.  **Запусти сервер** для проверки:
    ```
    python nowplaying.py
    ```

    Если всё работает, данные на странице начнут обновляться.

3.  **Автозапуск (рекомендуется):**
    *   Создай ярлык на файл start-nowplaying.vbs.
    *   Нажми Win + R, введи shell:startup и нажми Enter.
    *   Перемести ярлык в открывшуюся папку.
    *   Теперь сервер будет запускаться автоматически при входе в систему, без окна консоли.

## 📁 Структура проекта

*   home.html — основная HTML-страница с интерфейсом и логикой.
*   nowplaying.py — Python-скрипт для получения информации о текущем медиа.
*   start-nowplaying.vbs — VBS-скрипт для фонового запуска Python-сервера.
